## Golden rules
- Filter only -> `if` at the end.
- Choose between two values -> `if/else` at the front.
- Tuple comprehension does not exist -> use `tuple(...)` or a generator.
- If it needs more than 2 `for`s or gets hard to read -> use a normal loop.
